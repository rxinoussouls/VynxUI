# Elements Overview

VynxUI Modded now documents the element set by purpose instead of putting every control into one long mixed list.

![Elements preview](/vynxui/previews/vynxui-modded-preview.png)

## Core controls

| Element | Use it for |
| --- | --- |
| [Button](/docs/vynxui/button) | Run actions from a compact control. |
| [Toggle](/docs/vynxui/toggle) | Enable or disable a script feature. |
| [Slider](/docs/vynxui/slider) | Pick a numeric value quickly. |
| [Stepper](/docs/vynxui/stepper) | Mobile-friendly numeric changes with minus and plus controls. |
| [Input](/docs/vynxui/input) | Single-line text values. |
| [TextArea](/docs/vynxui/textarea) | Multi-line text input. |
| [Dropdown](/docs/vynxui/dropdown) | Pick from a list with fixed mobile positioning. |

## Selection groups

| Element | Use it for |
| --- | --- |
| [Segmented Control](/docs/vynxui/segmentedcontrol) | Switch between short modes. |
| [Radio Group](/docs/vynxui/radiogroup) | Choose one option from a visible set. |
| [Checkbox Group](/docs/vynxui/checkboxgroup) | Choose multiple options. |
| [Chip List](/docs/vynxui/chiplist) | Filter tags and small presets. |
| [Colorpicker](/docs/vynxui/colorpicker) | Pick colors for themes or features. |
| [Keybind](/docs/vynxui/keybind) | Bind keyboard and compact mobile actions. |

## Display and status

| Element | Use it for |
| --- | --- |
| [Paragraph](/docs/vynxui/paragraph) | Static text or media notes. |
| [Callout](/docs/vynxui/callout) | Important contextual messages. |
| [Badge](/docs/vynxui/badge) | Small labels and state chips. |
| [StatusCard](/docs/vynxui/statuscard) | Server, feature or runtime status. |
| [StatCard](/docs/vynxui/statcard) | Metrics such as FPS, ping or player count. |
| [KeyValue](/docs/vynxui/keyvalue) | Dense config summaries. |
| [ActionList](/docs/vynxui/actionlist) | Command rows with actions. |
| [MeterGroup](/docs/vynxui/metergroup) | Multiple progress values in one block. |
| [DiscordCard](/docs/vynxui/discordcard) | A dedicated Discord invite card with copy and join actions. |
| [Card](/docs/vynxui/card) | Visual page cards that open dedicated tabs, with optional nested content. |

## Layout and motion

| Element | Use it for |
| --- | --- |
| [Sections](/docs/vynxui/sections) | Organize content into collapsible groups. |
| [TabSection](/docs/vynxui/tabsection) | Split content inside a page. |
| [TabBox](/docs/vynxui/tabbox) | Multi-tab content inside a section box. |
| [Group](/docs/vynxui/group) | Visually combine related controls. |
| [HStack and VStack](/docs/vynxui/hstackvstack) | Build rows and columns inside examples or custom panels. |
| [Timeline](/docs/vynxui/timeline) | Show events and progress history. |
| [Accordion](/docs/vynxui/accordion) | Hide secondary details until needed. |
| [EmptyState](/docs/vynxui/emptystate) | Show an intentional blank state with action guidance. |
| [Path2D](/docs/vynxui/path2d) | Draw animated 2D paths. |
